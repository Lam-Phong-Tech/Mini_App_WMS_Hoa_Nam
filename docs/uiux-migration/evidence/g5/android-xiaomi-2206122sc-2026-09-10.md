## Blocking defect found

### G5-A01 — quote entry control is covered by native Zalo chrome

The AppShell HTML button labelled **“Chọn sản phẩm để gửi yêu cầu tư vấn”**
occupied `[1214,35][1386,206]` in the Android accessibility tree.  Zalo's
native close control occupied `[1267,111][1417,223]`, producing an overlap of
`[1267,111][1386,206]`.  A physical tap in that overlap activated Zalo's
native close control and returned to the Zalo inbox; it did not open
`/selection`.

This is a real-device safe-area/native-chrome collision, not a Green API
failure.  It blocks quote form focus/IME/validation testing and makes the
global quote entry route unavailable from this Android build.  No quote POST,
CRM/sale write or Customer/Production action was issued.

## Remediation prepared — pending device retest

The working tree now detects an installed Zalo Android/iOS runtime through
`getSystemInfo()` and puts the global quote target in a dedicated mobile row,
66 CSS px below the native upper-right chrome. Browser/desktop preview keeps
the original header layout. `typecheck`, `lint`, 62 unit tests and the
`backend-preview` build passed after this change. The revised bundle has not
yet been deployed; it must be opened through the local device-debug session
and retested on this Android device before G5-A01 can be closed.
